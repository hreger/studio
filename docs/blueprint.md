## Description

Oxbow Forecaster is a cutting-edge application designed to predict river course changes and the formation of oxbow lakes. Utilizing a sophisticated AI model and remote sensing data, this tool provides insights into potential future changes in river geography. This is useful for environmental management, land use planning, and understanding natural river dynamics.

## Features

-   **Oxbow Prediction**: Employs a pre-trained AI model to forecast river course changes and oxbow lake development based on hydrological data. The model analyzes historical and current river patterns to predict future shifts.
-   **Interactive Map**: Displays potential oxbow lake locations on an interactive map using remote sensing data. The map provides a visual representation of predicted changes, allowing users to interact with the data.
-   **Location Input**: Allows users to input specific location data to customize and refine predictions. By entering specific coordinates, users can generate predictions tailored to their areas of interest.
