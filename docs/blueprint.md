# **App Name**: Oxbow Forecaster

## Core Features:

- Oxbow Prediction: Use a pre-trained AI model tool to predict river course changes and oxbow lake formation based on hydrological data.
- Interactive Map: Display predicted oxbow lake locations on an interactive map using remote sensing data.
- Location Input: Allow users to input specific location data to refine predictions.

## Style Guidelines:

- Primary color: Deep blue (#2E4A62) to represent water and stability.
- Secondary color: Light green (#A3C4BC) to symbolize land and growth.
- Accent: Teal (#008080) for interactive elements and data highlights.
- Clean and modern layout with a focus on map visualization and data presentation.
- Use clear, informative icons for different data layers and functionalities.
